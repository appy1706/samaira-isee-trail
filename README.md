# Samaira's ISEE Trail

A daily ISEE Upper Level practice app for Samaira with two tracks that share one points bank:
- Words: a few new words a day as flashcards (meaning, similar word, sample sentence, prefix/root/suffix clues), then a quiz in the ISEE formats (synonyms, sentence completion, paired words).
- Math: one short lesson a day, then a quiz that only uses topics already learned.

There are two profiles: Samaira and Parent. The parent view shows progress for both tracks, topics and words needing work, and lets you set difficulty, pace, points and prizes.

## Put it on GitHub Pages
1. Create a new public repository (for example "samaira-isee-trail").
2. Upload every file in this folder to the repository root (index.html, words.js, content.js, manifest.json, sw.js, icon-192.png, icon-512.png).
3. Settings > Pages > Deploy from a branch > main > / (root).
4. Open the Pages address on the device. On a phone: Share > Add to Home Screen (iPhone) or Install app (Android).

First launch asks for a 4-digit PIN for the parent and for Samaira. Progress is saved in the browser on each device.
